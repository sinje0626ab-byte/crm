# 설원 바베큐 타이쿤 (Snow BBQ Tycoon) — YJ GAMES

WOS 플레이어블 광고 영상의 **아케이드 타이쿤** 메카닉을 그대로 옮긴 판입니다.
`game/` 의 기존 게임(화이트아웃 헌터)과는 별개로 돌아갑니다.

**주소:** https://sinje0626ab-byte.github.io/crm/game/arcade/

## 조작

| 기기 | 이동 |
|------|------|
| 휴대폰 | 화면 아무 곳이나 누르면 그 자리에 조이스틱 |
| PC | 방향키 또는 `WASD` (`ESC` 일시정지) |

**공격 버튼이 없습니다.** 곰·조리대·배식대·지폐·해금 구역 모두 **가까이 가면
자동으로** 때리고, 싣고, 내려놓고, 지불합니다.

## 핵심 루프

1. **사냥** — 위쪽 문으로 나가 북극곰 옆에 서면 자동으로 망치를 내려칩니다.
   쓰러지면 고기가 떨어지고, 지나가면 **등 뒤에 수직으로 쌓입니다**(최대치 있음)
2. **조리** — 그릴에 다가가면 등에 진 생고기가 한 장씩 들어가 구워지고,
   옆에 접시 더미가 쌓입니다
3. **배식** — 접시 더미에 다가가면 등에 싣고, 배식대에 다가가면 올려놓습니다
4. **판매** — 마을 주민이 줄을 서서 차례로 접시를 가져가고 **지폐를 바닥에 떨굽니다**
5. **수금 · 해금** — 지폐를 밟으면 등 뒤에 돈다발로 쌓이고(우측 상단 금액),
   바닥의 **원형 구역**에 올라서면 한 장씩 빠져나가며 금액이 줄어 해금됩니다

## 해금 구역

| 구역 | 시작 가격 | 효과 |
|------|-----------|------|
| 사냥꾼 | $20 (3회, ×2) | 곰을 잡아 고기를 그릴까지 나르는 일꾼 |
| 조리사 | $60 (2회, ×2.2) | 그릴 앞에 서서 굽는 속도를 올린다 |
| 배식원 | $120 (2회, ×2.2) | 접시를 배식대로 나르는 일꾼 |
| 이동 속도 | $80 (4회, ×1.7) | 플레이어 이동 속도 |
| 소지량 | $100 (4회, ×1.8) | 등에 쌓을 수 있는 최대 개수 |
| 고기 가격 | $150 (4회, ×1.9) | 손님이 내는 금액 |

지폐 한 장은 $10입니다.

## 코드 구조

요청하신 대로 시스템별로 파일을 나눴습니다.

| 파일 | 역할 |
|------|------|
| `src/config.js` | 배치·밸런스 상수와 팔레트 |
| `src/art.js` | 모든 모델(캐릭터·곰·그릴·배식대·울타리·원형 구역·라벨) |
| `src/world.js` | 씬·조명·카메라(쿼터뷰 추적)·눈밭·마당·눈발 |
| `src/nav.js` | 울타리 통과 규칙, 이동·걷기 애니메이션 헬퍼 |
| **`src/player.js`** | **플레이어 이동 + 접촉 자동 공격/수거/납품** |
| **`src/stack.js`** | **등 뒤 스태킹(수직 적재 + 흔들림)** |
| **`src/zones.js`** | **원형 트리거 구역 기반 해금/업그레이드** |
| **`src/customers.js`** | **손님 대기열 AI(줄서기 → 구매 → 지폐 투하 → 퇴장)** |
| `src/workers.js` | 일꾼 AI(사냥꾼·조리사·배식원) |
| `src/bears.js` | 사냥터 야수 생성·배회·피격 |
| `src/stations.js` | 조리대(굽기 큐·접시 더미)와 배식대(접시 슬롯) |
| `src/drops.js` | 바닥에 떨어진 고기·지폐 |
| `src/hud.js`, `src/menu.js`, `src/save.js` | 현금 UI, 인트로·메뉴·일시정지, 저장 |
| `src/main.js` | 위 시스템을 엮는 게임 루프 |

Three.js와 YJ GAMES 로고, 사운드 엔진(`../vendor`, `../assets`, `../src/audio.js`)은
기존 게임과 함께 씁니다.

## 인트로

YJ GAMES 로고와 함께 **징글**(도–미–솔–도–미 상행 + 패드 + 반짝임)이 깔립니다.
브라우저 자동재생 정책 때문에 첫 방문에서 소리가 막히면, 화면을 한 번 누르는
순간 울립니다.
