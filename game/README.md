# 화이트아웃 헌터 (Whiteout Hunter)

WOS(화이트아웃 서바이벌) 광고에 나오는 **설원 아이들 타이쿤 + 서바이버**
스타일을 실제로 플레이할 수 있게 만든 게임입니다. Three.js 로우폴리 3D,
빌드 도구 없이 정적 파일로만 동작합니다.

**주소:** https://sinje0626ab-byte.github.io/crm/game/ (main 브랜치 배포 후)

## 조작

| 기기 | 조작 |
|------|------|
| 휴대폰 | 화면 아무 곳이나 누르면 그 자리에 조이스틱이 생깁니다 |
| PC | `WASD` 또는 방향키 |

공격은 자동입니다. 캐릭터 주위를 도는 도끼에 야수가 닿으면 피해를 줍니다.

## 게임 루프

1. 캠프 오른쪽 문으로 나가 **사냥터**에서 북극곰을 잡는다
2. 떨어진 **고기**를 밟아 머리 위에 싣는다 (최대 10개)
3. 캠프의 **화로**에 가까이 가면 고기가 자동으로 들어가 조리된다
4. 조리된 만큼 **돈다발**이 캠프 한쪽에 쌓인다 → 밟아서 수금
5. **구매 패드** 위에 서 있으면 돈이 빠져나가며 시설이 해금된다

| 패드 | 가격 | 효과 |
|------|------|------|
| 일꾼 | $100 (최대 3명, 구매마다 1.8배) | 고기를 자동으로 주워 화로에 넣는다 |
| 궁수 | $175 × 2 | 망루에서 사냥터의 야수를 자동 사격 |
| 도끼 강화 | $400 (최대 5단계, 1.6배) | 도끼 개수 +1, 피해량 +11 |

체력이 0이 되면 잠시 기절했다가 캠프에서 부활하고, 들고 있던 고기의 절반을
잃습니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | HUD(DOM 오버레이) + 스타일 + 모듈 진입점 |
| `src/config.js` | **밸런스 상수 모음** — 숫자만 바꿔도 난이도가 달라집니다 |
| `src/world.js` | 씬·카메라·조명·눈 지형·숲·캠프 바닥/울타리 |
| `src/entities.js` | 모든 로우폴리 메시 빌더(캐릭터, 곰, 도끼, 패드, 라벨) |
| `src/main.js` | 게임 루프와 시스템(전투·운반·조리·구매·AI) |
| `src/input.js` | 키보드 + 플로팅 조이스틱 |
| `src/hud.js` | 돈·체력·적재량·토스트 갱신 |
| `vendor/three.module.js` | Three.js r169 (CDN 의존 없이 저장소에 포함) |

## 개발 메모

- 외부 네트워크 요청이 전혀 없어 오프라인에서도 그대로 돌아갑니다.
- 브라우저 콘솔에서 `__game` 으로 상태를 들여다볼 수 있습니다.
  예) `__game.S.money = 5000`, `__game.spawnBear()`
- 로컬 실행: 저장소 루트에서 `npx http-server -p 8123` 후
  `http://127.0.0.1:8123/game/` 접속 (ES 모듈이라 `file://` 로는 열리지 않습니다)
