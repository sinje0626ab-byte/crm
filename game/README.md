# 화이트아웃 헌터 (Whiteout Hunter) — YJ GAMES

WOS(화이트아웃 서바이벌) 광고에 나오는 **설원 아이들 타이쿤**을 실제로
플레이할 수 있게 만든 게임입니다. Three.js 로우폴리 3D, 빌드 도구 없이
정적 파일로만 동작합니다.

**주소:** https://sinje0626ab-byte.github.io/crm/game/

## 흐름

YJ GAMES 인트로 → 메인 메뉴(이어하기 / 새 게임) → 게임 → ☰ 버튼이나 `ESC` 로
일시정지 (계속하기 / 저장하기 / 소리 / 저장하고 메뉴로)

인트로 로고는 **언데드러쉬와 같은 것**입니다. `test` 저장소의
`undead-rush.html` 안에 base64로 박혀 있던 이미지를 꺼내
`assets/yj-games.webp` 로 저장했고, 스플래시 CSS 애니메이션(2.6초,
탭하면 건너뜀)도 그쪽과 같은 규칙으로 맞췄습니다.

진행 상황은 12초마다, 그리고 시설을 구매할 때마다 자동 저장됩니다.
저장은 브라우저(localStorage)에 남으므로 **기기·브라우저마다 따로** 관리됩니다.

## 조작

| | 이동 | 공격 | 스킬 |
|---|------|------|------|
| **PC** | 방향키 | `A` | `S` · `D` · `F` |
| 공통 | `ESC` 일시정지 · `I` 아이템창 · 좌하단 **아이템** 버튼 | | |
| **휴대폰** | 화면 아무 곳이나 누르면 그 자리에 조이스틱 | 우측 하단 **A** 버튼 | 우측 하단 스킬 버튼 |

> PC에서 `A`·`S`가 공격·스킬로 쓰이므로 **이동은 방향키**입니다 (WASD 아님).
> `ESC` 를 누르면 일시정지 메뉴가 열리고, 한 번 더 누르면 게임으로 돌아갑니다.

나무나 야수가 사정거리에 들어오면 캐릭터 옆에 **키 안내**가 뜹니다.
A는 누르고 있으면 계속 휘두릅니다. 스킬 버튼·키캡에는 쿨타임 게이지가
줄어들고 남은 초가 숫자로 뜨며, 다 차면 한 번 번쩍이고 준비음이 납니다.

## 레벨과 스킬

야수를 잡고(등급별 12~70), 나무를 베고(5), 물건을 팔면(개당 2) 경험치가 쌓입니다.
**Lv.1은 공격만 가능하고, Lv.2부터 스킬을 하나 골라 습득**합니다. 레벨업마다
카드 세 장이 뜨고 새 스킬 습득 · 기존 스킬 강화(최대 5레벨) · 능력치 중에서
고릅니다.

| 스킬 | 키 | 쿨타임 | 효과 |
|------|----|--------|------|
| **회전베기** | `S` | 9초 | 제자리에서 돌며 반경 6.8 안의 야수를 피해 2.4배로 베고 나무도 찍는다 |
| **돌진베기** | `D` | 7초 | 앞으로 13만큼 내달리며 스치는 야수를 피해 2.0배로 베고 크게 밀어낸다 |
| **서리폭발** | `F` | 12초 | 반경 9에 피해 1.7배 + 야수를 4.5초 동안 느리게 만든다 |

강화하면 피해·범위·거리·둔화 시간이 늘고 쿨타임이 줄어듭니다.
능력치 카드는 최대 체력 +25, 이동 속도 +8%, 검 피해 +10 중에서 나옵니다.

## 낮과 밤

2분 낮 → 1분 15초 밤이 반복되고, 해질녘·새벽에는 하늘빛이 서서히 바뀝니다.
**밤에는 야수가 더 많이, 더 자주 나옵니다** (동시 최대 20 → 34마리, 출현
주기 절반). 28% 확률로 한 등급 위의 놈이 내려오기도 합니다.
밤에는 별이 뜨고 **캐릭터가 횃불을 들어** 주변을 밝힙니다. 상단의 해/달 표시로
며칠째인지 알 수 있습니다.

**정착지는 밤에도 환합니다.** 캠프 전체를 덮는 따뜻한 조명과 횃불, 화로 불빛이
켜져 있어 바깥의 어두운 설원과 뚜렷하게 대비됩니다.

## 집(정착지)

밖에서 보면 정착지는 **벽과 눈 덮인 박공지붕, 굴뚝을 갖춘 집** 한 채입니다.
문(동쪽 출입구)으로 들어가면 벽과 지붕이 스르륵 사라지고 지금처럼 트인
내부가 드러납니다. 지붕이 카메라와 캐릭터 사이를 가리는 위치(집 북쪽 등)에
서도 자동으로 사라지므로 시야가 막히지 않습니다. 밤에는 창문에 불이 들어옵니다.

## 아이템창

`I` 키나 좌하단 **아이템** 버튼으로 엽니다(다시 누르거나 `ESC` 로 닫힘).
여는 동안 게임은 멈춥니다.

- **생존자**: 레벨, 경험치, 체력, 검 피해, 이동 속도 보너스
- **소지품**: 들고 있는 나무·고기(각각 한도 포함), 돈
- **판매대 재고**: 통나무, 구운 고기, 화로에서 굽는 중인 수
- **시설 · 장비**: 검/가방 레벨, 일꾼 수, 궁수 망루 수
- **스킬**: 3종의 습득 여부와 레벨
- **기록**: 며칠째 낮/밤인지, 물건을 판 손님 수

## 미니맵

**정착지 밖으로 나가면** 우측 상단에 미니맵이 뜹니다(안에 있으면 사라집니다).
정착지(금색)·벌목장(초록)·사냥터(파랑) 구역과 함께 살아있는 나무, 떨어진 자원,
야수, 손님, 시설 위치가 표시되고, 흰 삼각형이 내 위치와 보는 방향입니다.
야수는 등급에 따라 빨강(북극곰)·주황(회색곰)·보라(흑곰 대장)로 구분됩니다.

## 게임 루프

1. **북쪽 숲**에서 나무를 벱니다 (3번 휘두르면 쓰러지고 통나무 3개가 떨어짐)
2. **사냥터와 숲**에서 야수를 잡으면 고기가 떨어집니다. 정착지에서 멀어질수록
   더 강한 놈이 나옵니다 — 북극곰(110) → 회색곰(280) → 흑곰 대장(640).
   깊이 들어갈수록 고기와 경험치도 많이 줍니다
3. 자원을 밟으면 머리 위에 **나무는 오른쪽, 고기는 왼쪽**으로 따로 쌓입니다.
   종류마다 적재 한도가 따로라(HUD에 `나무 n/10`, `고기 n/10`으로 각각 표시)
   한쪽이 가득 차도 다른 쪽은 계속 담을 수 있습니다
4. 정착지로 돌아와 **나무는 판매대**에, **고기는 화로**에 내려놓습니다
   (고기는 화로에서 구워진 뒤 판매대 재고가 됩니다)
5. 재고가 있으면 **손님**이 판매대 앞 줄에 나타나 차례를 기다리고, 원하는
   만큼 사 간 뒤 돈을 놓고 물러납니다 (앞사람이 빠지면 한 칸씩 당겨 섭니다)
6. 쌓인 **돈다발을 밟아 수금**하고, 구매 패드에서 시설을 늘립니다

| 패드 | 가격 | 효과 |
|------|------|------|
| 일꾼 | $120 (최대 3명, 1.8배씩) | 떨어진 자원을 주워 납품 (나무는 판매대, 고기는 화로로) |

| 가방 | $220 (최대 3단계, 1.7배씩) | 적재량 +5 |
| 검 | $400 (최대 5단계, 1.6배씩) | 피해량 +15, 휘두르는 속도 증가 |
| 궁수 | $175 × 2 | 망루에서 야수를 자동 사격 |

가격: 나무 개당 $14, 구운 고기 개당 $24.
체력이 0이 되면 잠시 기절했다가 정착지에서 부활하고 짐의 절반을 잃습니다.

## 소리

음원 파일 없이 **Web Audio로 직접 합성**합니다. 언데드러쉬의 사운드 엔진
(`tone` / `noise` 신시사이저, 동시 발성 제한, 음소거)을 그대로 가져와
이 게임의 효과음과 배경음을 얹었습니다.

- **효과음**: 검 휘두르기, 나무 찍기/쓰러짐, 야수 타격/처치, 화살, 피격,
  기절, 자원 줍기, 납품, 조리, 손님 도착, 판매 완료, 동전, 시설 구매,
  가방 가득참 경고, UI 클릭
- **배경음**: 느린 단조 패드(Am–F–C–G) + 드문드문 울리는 종소리 + 바람 소리.
  파일 루프가 아니라 실시간 스케줄링이라 매번 조금씩 다르게 들립니다.
- 브라우저 정책상 **첫 터치·클릭 이후** 소리가 시작됩니다.
- 좌상단 스피커 버튼이나 일시정지 메뉴에서 끌 수 있고, 설정은 저장됩니다.

## 개발 메모

- 외부 네트워크 요청이 전혀 없어 오프라인에서도 그대로 돌아갑니다.
- 브라우저 콘솔에서 `__game` 으로 상태를 볼 수 있습니다.
  예) `__game.S.money = 5000`, `__game.spawnBear()`, `__game.snapshot()`
- 로컬 실행: 저장소 루트에서 `npx http-server -p 8123` 후
  `http://127.0.0.1:8123/game/` 접속 (ES 모듈이라 `file://` 로는 열리지 않습니다)
- 성능: 울타리와 배경 나무는 InstancedMesh로 묶여 있습니다. 점광원은 낮에는
  화로 하나, 밤에는 캠프 조명·횃불·손횃불까지 다섯 개가 켜집니다. 무거워지면
  `config.js` 의 `sceneryTrees`, `world.js` 의 `FLAKES`(눈발 개수)와 횃불
  광원 수, 그림자 해상도를 먼저 줄이세요.
- 조명 주의: three r155+ 는 점광원이 **거리제곱으로 감쇠**합니다. 높은 곳에
  단 조명은 세기를 크게(수십 단위) 잡아야 바닥이 밝아집니다.
