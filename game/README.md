# 화이트아웃 헌터 (Whiteout Hunter) — YJ GAMES

WOS(화이트아웃 서바이벌) 광고에 나오는 **설원 아이들 타이쿤**을 실제로
플레이할 수 있게 만든 게임입니다. Three.js 로우폴리 3D, 빌드 도구 없이
정적 파일로만 동작합니다.

**주소:** https://sinje0626ab-byte.github.io/crm/game/

## 흐름

YJ GAMES 인트로 → 메인 메뉴(이어하기 / 새 게임) → 게임 → ☰ 일시정지
(계속하기 / 저장하기 / 저장하고 메뉴로)

진행 상황은 12초마다, 그리고 시설을 구매할 때마다 자동 저장됩니다.
저장은 브라우저(localStorage)에 남으므로 **기기·브라우저마다 따로** 관리됩니다.

## 조작

| 기기 | 조작 |
|------|------|
| 휴대폰 | 화면 아무 곳이나 누르면 그 자리에 조이스틱이 생깁니다 |
| PC | `WASD` 또는 방향키 |

공격은 자동입니다. 검을 든 채로 가까운 야수나 나무를 향해 몸을 돌려 휘두릅니다.

## 게임 루프

1. **북쪽 숲**에서 나무를 벱니다 (3번 휘두르면 쓰러지고 통나무 3개가 떨어짐)
2. **남쪽 사냥터**에서 북극곰을 잡으면 고기가 떨어집니다
3. 자원을 밟아 머리 위로 쌓습니다 — 가방이 차면 **FULL** 이 뜨고 더 담기지 않습니다
4. 정착지로 돌아와 **나무는 판매대**에, **고기는 화로**에 내려놓습니다
   (고기는 화로에서 조리된 뒤 판매대 재고가 됩니다)
5. 재고가 있으면 **손님**이 찾아와 줄을 서고, 원하는 만큼 사 간 뒤 돈을 놓고 갑니다
6. 쌓인 **돈다발을 밟아 수금**하고, 구매 패드에서 시설을 늘립니다

| 패드 | 가격 | 효과 |
|------|------|------|
| 일꾼 | $120 (최대 3명, 1.8배씩) | 떨어진 자원을 주워 알아서 납품 |
| 가방 | $220 (최대 3단계, 1.7배씩) | 적재량 +5 |
| 검 | $400 (최대 5단계, 1.6배씩) | 피해량 +15, 휘두르는 속도 증가 |
| 궁수 | $175 × 2 | 망루에서 야수를 자동 사격 |

가격: 나무 개당 $14, 조리된 고기 개당 $24.
체력이 0이 되면 잠시 기절했다가 정착지에서 부활하고 짐의 절반을 잃습니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 인트로·메뉴·일시정지·HUD(DOM) + 스타일 + 모듈 진입점 |
| `src/config.js` | **밸런스 상수 모음** — 숫자만 바꿔도 난이도가 달라집니다 |
| `src/world.js` | 씬·카메라·조명·눈 지형·숲·정착지·눈발 파티클 |
| `src/entities.js` | 로우폴리 메시 빌더(캐릭터, 검, 곰, 나무, 화로, 판매대, 라벨) |
| `src/main.js` | 게임 루프와 시스템(전투·벌목·운반·조리·판매·구매·AI·저장) |
| `src/input.js` | 키보드 + 플로팅 조이스틱 |
| `src/hud.js` | 돈·재고·체력·적재량·토스트 갱신 |
| `src/menu.js` | 인트로 → 메뉴 → 일시정지 흐름 |
| `src/save.js` | localStorage 저장/불러오기 |
| `vendor/three.module.js` | Three.js r169 (CDN 의존 없이 저장소에 포함) |

## 개발 메모

- 외부 네트워크 요청이 전혀 없어 오프라인에서도 그대로 돌아갑니다.
- 브라우저 콘솔에서 `__game` 으로 상태를 볼 수 있습니다.
  예) `__game.S.money = 5000`, `__game.spawnBear()`, `__game.snapshot()`
- 로컬 실행: 저장소 루트에서 `npx http-server -p 8123` 후
  `http://127.0.0.1:8123/game/` 접속 (ES 모듈이라 `file://` 로는 열리지 않습니다)
- 성능: 울타리와 배경 나무는 InstancedMesh로 묶여 있고, 점광원은 화로 하나만
  씁니다. 무거워지면 `config.js` 의 `sceneryTrees`, `world.js` 의 `FLAKES`
  (눈발 개수), 그림자 해상도를 먼저 줄이세요.
