# 바른비즈 CRM (회사업무용 관리시스템)

단일 HTML 파일로 동작하는 고객관리 시스템입니다. GitHub Pages로 배포하면
설치 없이 브라우저 주소만으로 바로 사용할 수 있습니다.

**접속 주소:** https://sinje0626ab-byte.github.io/crm/

## 주요 기능

- 신규 고객 등록 및 고객 카드 관리
- 💰 수금관리
- 📊 대출계산기
- 💬 상담진행 기록
- 🗑 휴지통 (삭제 복구)
- 백업 내보내기 / 불러오기
- 다크모드 · 라이트모드, 폰트 및 화면 배율 설정

## 최초 1회 설정 (GitHub Pages 켜기)

이 저장소를 처음 사이트로 만들 때 한 번만 하면 됩니다.

1. GitHub 저장소 → **Settings** → 왼쪽 메뉴 **Pages**
2. **Build and deployment** → **Source** 를 **GitHub Actions** 로 선택
3. `main` 브랜치에 코드가 올라가면 자동으로 배포됩니다
   (**Actions** 탭에서 진행 상황 확인 가능, 보통 1~2분 소요)
4. 배포가 끝나면 위 접속 주소로 들어갑니다

이후에는 `index.html` 을 수정해서 `main` 에 올릴 때마다 사이트가 자동으로 갱신됩니다.

## 사용 시 꼭 알아두실 점 ⚠️

### 1. 데이터는 "사용하는 브라우저 안"에만 저장됩니다

이 시스템은 서버 없이 동작하며, 모든 데이터를 브라우저의 로컬 저장소
(localStorage)에 보관합니다. 따라서:

- **PC와 휴대폰의 데이터는 서로 공유되지 않습니다**
- **직원끼리 데이터가 공유되지 않습니다** (각자 자기 브라우저에만 쌓입니다)
- 크롬 **시크릿 모드**에서는 창을 닫으면 데이터가 사라집니다
- 브라우저 **인터넷 사용기록 / 쿠키 및 사이트 데이터 삭제** 시 자료가 함께 지워집니다

### 2. 정기적으로 백업을 받아두세요

프로그램 안의 **백업** 기능으로 파일을 내려받아 보관하시고, 다른 PC나
휴대폰에서 이어서 쓸 때는 그 파일을 **불러오기** 하시면 됩니다.
기기 변경·브라우저 초기화 전에는 반드시 백업을 먼저 받으세요.

### 3. 저장소가 Public이면 주소를 아는 사람은 누구나 접속할 수 있습니다

단, 접속해도 보이는 것은 **빈 화면(그 사람의 빈 데이터)** 이며 우리 회사
고객정보가 보이는 것은 아닙니다. 고객정보는 각자 브라우저에만 있기 때문입니다.
그래도 외부 접속 자체를 막고 싶다면 저장소를 **Private** 으로 바꾸고
GitHub Pages 유료 플랜(Enterprise)을 쓰거나, 사내 다른 배포 방법을 고려하세요.

## 휴대폰에서 앱처럼 쓰기

- **아이폰(Safari):** 접속 → 공유 버튼 → `홈 화면에 추가`
- **안드로이드(Chrome):** 접속 → 우측 상단 ⋮ → `홈 화면에 추가`

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | CRM 프로그램 본체 (v11.1, 단일 파일) |
| `.github/workflows/pages.yml` | main 브랜치 푸시 시 자동 배포 |
| `.nojekyll` | GitHub Pages의 Jekyll 처리 비활성화 |

인터넷 연결은 글꼴(Google Fonts)을 불러올 때만 사용하며, 연결이 없어도
기본 글꼴로 정상 동작합니다.
