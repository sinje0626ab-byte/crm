# 바른비즈 CRM (회사업무용 관리시스템)

단일 HTML 파일로 동작하는 고객관리 시스템입니다. GitHub Pages로 배포하면
설치 없이 브라우저 주소만으로 바로 사용할 수 있습니다.

**접속 주소:** https://sinje0626ab-byte.github.io/crm/

## 주요 기능

- 신규 고객 등록 및 고객 카드 관리
- 💰 수금관리
- 📊 대출계산기
- 💬 상담진행 기록
- 🗑 휴지통 (삭제 복구)
- 백업 내보내기 / 불러오기
- 다크모드 · 라이트모드, 폰트 및 화면 배율 설정

## 접속 비밀번호

사이트에 들어가면 먼저 잠금화면이 뜨고, 숫자판으로 **4931** 을 누르면
CRM으로 진입합니다. 키보드 숫자키로도 입력할 수 있습니다.

- 4자리를 다 누르면 자동으로 확인됩니다 (엔터 불필요)
- 틀리면 화면이 흔들리고 다시 입력할 수 있습니다
- `지우기` 한 자 삭제 / `전체지움` 전부 삭제 (키보드 Backspace · Esc)
- 한 번 통과하면 **그 탭을 닫을 때까지** 다시 묻지 않습니다
  (새로고침은 그대로 통과, 브라우저나 탭을 닫았다 열면 다시 입력)

비밀번호를 바꾸려면 `index.html` 에서 아래 한 줄만 고치면 됩니다.

```js
var PASSCODE = '4931';
```

> ⚠️ **이 잠금은 '가벼운 잠금'입니다.** 서버가 없는 정적 사이트라 비밀번호가
> `index.html` 안에 들어 있고, 소스보기를 할 줄 아는 사람은 확인하거나 우회할 수
> 있습니다. 모르는 사람이 주소만 알고 들어왔을 때 막는 용도로는 충분하지만,
> 진짜 보안이 필요하다면 서버 인증이 필요합니다.
> 다만 **고객 데이터는 각자 브라우저에만 저장**되므로, 외부인이 잠금을 넘어와도
> 우리 회사 고객정보가 보이는 것은 아닙니다 (빈 화면이 보입니다).

## 배포 (이미 설정 완료됨)

사이트는 이미 켜져 있습니다. `main` 브랜치에 푸시하면 GitHub Actions가
자동으로 다시 배포합니다 (**Actions** 탭에서 진행 확인, 보통 1~2분).

즉, `index.html` 을 고쳐서 `main` 에 올리기만 하면 사이트가 갱신됩니다.
수동으로 다시 돌리고 싶으면 **Actions → Deploy to GitHub Pages → Run workflow**.

> 참고: 이 저장소는 GitHub Pages를 쓰기 위해 **Public** 으로 되어 있습니다.
> 무료 플랜에서는 Private 저장소로 Pages 사이트를 만들 수 없습니다.

## 사용 시 꼭 알아두실 점 ⚠️

### 1. 데이터는 "사용하는 브라우저 안"에만 저장됩니다

이 시스템은 서버 없이 동작하며, 모든 데이터를 브라우저의 로컬 저장소
(localStorage)에 보관합니다. 따라서:

- **PC와 휴대폰의 데이터는 서로 공유되지 않습니다**
- **직원끼리 데이터가 공유되지 않습니다** (각자 자기 브라우저에만 쌓입니다)
- 크롬 **시크릿 모드**에서는 창을 닫으면 데이터가 사라집니다
- 브라우저 **인터넷 사용기록 / 쿠키 및 사이트 데이터 삭제** 시 자료가 함께 지워집니다

### 2. 정기적으로 백업을 받아두세요

프로그램 안의 **백업** 기능으로 파일을 내려받아 보관하시고, 다른 PC나
휴대폰에서 이어서 쓸 때는 그 파일을 **불러오기** 하시면 됩니다.
기기 변경·브라우저 초기화 전에는 반드시 백업을 먼저 받으세요.

### 3. 저장소가 Public이라 주소를 아는 사람은 접속할 수 있습니다

1차로 비밀번호 잠금화면이 막아주지만, 위에 적었듯이 그 비밀번호는 소스에서
확인할 수 있습니다. 다만 **잠금을 넘어와도 보이는 것은 빈 화면**입니다.
고객정보는 저장소가 아니라 각자 브라우저에만 있기 때문입니다.

외부 접속 자체를 차단해야 한다면:

- 저장소를 Private으로 되돌리고 **GitHub Pro 이상**(Pages 지원 플랜) 사용
- 또는 **Netlify · Cloudflare Pages** 등으로 배포 (Private 저장소도 무료)

## 휴대폰에서 앱처럼 쓰기

- **아이폰(Safari):** 접속 → 공유 버튼 → `홈 화면에 추가`
- **안드로이드(Chrome):** 접속 → 우측 상단 ⋮ → `홈 화면에 추가`

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | CRM 프로그램 본체 (v11.1, 단일 파일) + 비밀번호 잠금화면 |
| `.github/workflows/pages.yml` | main 브랜치 푸시 시 자동 배포 |
| `.nojekyll` | GitHub Pages의 Jekyll 처리 비활성화 |

인터넷 연결은 글꼴(Google Fonts)을 불러올 때만 사용하며, 연결이 없어도
기본 글꼴로 정상 동작합니다.
